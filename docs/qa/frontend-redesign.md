# 译羽前端重构验收记录

日期：2026-11-17。视觉基准与并排审阅见仓库根目录 `design-qa.md`。

## 已验证

- 浏览器模拟：主窗口 980 × 660 和 760 × 500、浅色与深色、有图与无图；选图预览、取消、应用、重载、移除、图片不可用回退；长原文、流式翻译、取消、历史、错误和设置草稿；浮窗复制、重试、固定和 Esc；键盘选择菜单、焦点、提示及减弱动效。
- 对比度：用纯白、纯黑和黑白高对比三张模拟图片，在浅色和深色主题逐一截图，检查阅读区正文与占位文字相对实际渲染背景均至少 4.5:1。测试采样不代替所有图片和平台的人工复核。
- macOS Tauri：独立 `Yiyu Frontend QA` 测试包和临时数据目录；从首次配置进入主窗口，选择本地 PNG、预览和应用，主窗口实时更新，切换浅深主题；重启测试进程后恢复背景和深色主题。为重新进入测试窗口，仅在隔离测试数据中重置首次配置标记。未覆盖已安装的用户应用或其数据。
- Rust：旧配置兼容、图片格式/字节数/尺寸/损坏数据、受控路径、清理边界、并发替换、版本冲突、持久化失败保留旧背景和图片丢失恢复。

## 资源与权限边界

用户通过系统选图器明确选择图片；前端在内存中预览并通过 IPC 传给 Rust，Rust 校验 PNG/JPEG 内容及解码尺寸后写入应用数据目录的 `backgrounds/`，设置只保存 UUID。读取和删除仅使用受验证的应用资源标识，不接受任意文件路径；不修改源文件，不把图片加入翻译请求或日志。现有 CSP 的 `data:` 仅用于本地预览和应用内渲染；本次未新增 filesystem、shell、网络或资源协议能力。现有 CSP 中其他来源属于原配置，并非本次新增授权。

## 自动检查

- `pnpm typecheck`、`pnpm build:web`：通过。
- `pnpm test`：6 个测试文件、18 个测试通过。
- `pnpm qa:interactions`：通过，包括 6 组明暗主题/背景的正文和占位文字对比测量。
- `pnpm qa:screenshots` 与 `pnpm qa:screenshots:compare`：20 张截图重新生成并通过基线比较。原基线备份于本机 `/tmp/yiyu-baselines-before-frontend-redesign`。
- `cargo test --workspace`：应用 30 项、核心 42 项通过；背景恢复补充测试及 `cargo check --workspace` 通过。
- `openspec validate --all --strict`：两个进行中的变更均通过。

## 尚待验证

- macOS：真实划词时快捷浮窗的非激活焦点、外部窗口模糊、多显示器定位与空闲性能；不能由应用内部图片模糊推断窗口外桌面模糊。
- Windows：实际 WebView 材质、选图持久化、焦点、DPI、多显示器与性能。当前环境无法执行 Windows 真机测试。
- 实际模型服务、系统划词及端到端联网翻译仍需独立验收；浏览器模拟与 Rust 单元测试不等同于真实服务测试。

## 2026-11-17 用户反馈后的补充验收

- 主窗口、设置窗口和首次配置共用内置或自定义图片；浅色、深色、无背景、三张内置图与用户图片的选择均在浏览器交互中检查。新增无背景和内置背景的重载测试，保留原图片不可用和极端亮暗图片测试。
- macOS：使用独立 bundle identifier、仅含本地测试服务的临时数据目录以及禁用的测试快捷键，实际查看主窗口和设置窗口，切换深色、海岸及无背景，确认设置写入隔离配置文件。未连接真实模型、读取用户密钥或修改用户现有设置。
- 设置窗口最低尺寸下可独立滚动模型列表；外观、独立快捷键页面、快捷键录入和草稿保存经浏览器交互验证。
- `cargo test --workspace`：应用 30 项、核心 44 项通过；`cargo clippy --workspace --all-targets -- -D warnings` 和 `cargo fmt --all -- --check` 通过。
- 新版视觉重新生成截图，人工检查浅深色、最小窗口、外观及快捷键页面。旧版截图基线不代表这次主动调整后的新设计，本轮未声称通过旧基线差异比较。
- 旧版的空背景配置无法区分“从未选择背景”和“用户主动移除背景”，升级时统一显示新默认图；已有自定义图片保持不变。升级后选择的“无背景”明确持久化。

## 2026-11-18 窗口与权限复查

- 浏览器模拟覆盖浅深主题的快捷浮窗、权限错误和背景，以及清空历史、删除服务、自定义语言对话框的确认与取消；连续启动翻译时验证新会话替换旧结果。
- macOS 使用独立测试包和隔离数据验证应用内对话框，以及从设置直接打开“设备控制和数据访问”；未修改系统授权开关或用户数据。
- 检查时 `Yiyu.app` 与独立测试包的系统授权开关均为关闭；尚未验证最终签名构建授权后返回时的状态刷新或真实应用选区取词。检查时机器尚无可用代码签名身份，ad-hoc 构建的身份会随内容变化。
- 原生菜单的功能与快捷键连接已实现；菜单实际显示、系统快捷键和其他应用选区仍需在最终构建授权后进行真机验收。Windows 和真实模型服务未在本轮验证。

## 2026-11-18 本地开发签名

- 在不修改系统证书信任与辅助功能授权的情况下，将本地自签名身份保存到用户钥匙串；重复配置确认复用该身份。`pnpm build:macos:local` 已生成签名的调试应用。
- 更改应用包版本信息后，用同一身份重新签名的副本与构建产物双向满足彼此的代码身份要求；签名后的应用使用临时数据、关闭更新和快捷键启动成功。
- 此检查不等于系统授权后的真实划词验收。自签名仅供本机开发，不能用于 Apple 公证或正式分发。
