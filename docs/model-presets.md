# 模型预设维护

预设只用于新建配置；升级应用不会改写已有服务商、模型、密钥或本地模型。模型可用性和价格会变化，实际可用模型以设置中的「获取模型」和服务商账户为准。

2026-11-17 核对的来源：

- OpenAI: `gpt-6-luna`，见 [模型目录](https://developers.openai.com/api/docs/models)。
- DeepSeek: `deepseek-flash`，见 [模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)。
- 智谱: `glm-5.3-flash`，见 [GLM-5.3-Flash](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)。
- Kimi: `kimi-k3.1-pro`，见 [Kimi API 调用说明](https://platform.kimi.com/docs/guide/kimi-k3-1-pro-quickstart)。不同地区账户的模型权限可能不同。
- 硅基流动: `deepseek-ai/DeepSeek-V4.1-Flash`，见 [服务公告](https://docs.siliconflow.cn/docs/release-notes/overview)。
- OpenRouter: `openrouter/auto`，见 [自动路由说明](https://openrouter.ai/blog/announcements/introducing-the-new-auto-router/)。
- Ollama: `qwen3.5:4b` 仅为配置示例，不会自动下载或假定已安装；以本地获取的模型列表为准。见 [模型目录](https://ollama.com/library/qwen3.5)。LM Studio 同样以本地实际加载的模型为准。
