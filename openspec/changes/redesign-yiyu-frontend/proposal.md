# Proposal

## Why

译羽当前前端虽然覆盖了首版功能，但页面层级、材质和交互细节尚未达到用户对精美 Tauri 桌面应用的预期。用户已确认以普通高斯模糊玻璃、浅深双主题和可自定义背景图片作为整体重构方向，需要在保留现有翻译能力的同时建立一致、可验收的界面体验。

## What Changes

- 重构主窗口、快捷浮窗、设置和首次配置，统一排版、玻璃材质、组件、图标与交互状态；优化常见及最小窗口尺寸下的布局。
- 实现浅色、深色和跟随系统主题，使用适量强调色；玻璃效果以半透明表面和高斯背景模糊为主，避免厚重浮雕、过强发光和装饰性背景。
- 默认提供多张本地自然风景背景，支持无背景，并让主窗口、设置、首次配置及快捷浮窗共用背景；保留用户已有图片。
- 将设置拆分为通用、外观、模型、快捷键、网络、更新与关于，精简标题栏并统一字体和选中状态。
- 更新新增配置的模型预设，并允许已有配置手动采用推荐模型；不覆盖已保存的模型或密钥。
- 新增本地自定义背景图片：选择、预览、应用、替换、移除和重启恢复；图片不可读时回退至主题底色并提供恢复提示。
- 保留翻译、流式、停止、重试、历史、模型配置、设置、更新和系统窗口行为，移除收藏入口并保留旧记录，补齐键盘、可访问性、低动效、失败恢复及视觉回归验证。
- 依据真实 macOS/Windows 窗口合成效果选择玻璃实现与降级方式，避免仅凭浏览器 mock 宣称原生效果已经可用。
- 不改变 LLM 协议或翻译业务规则；背景图片仅在本机处理，不引入远程图片服务。

## Capabilities

### New Capabilities

- `desktop-appearance`: 为各桌面界面定义统一的浅深主题、轻量玻璃材质、响应式布局与可访问状态。
- `custom-background`: 定义用户选择、预览、持久化、替换、移除本地背景图片及失败恢复的行为。

### Modified Capabilities

无。当前 `openspec/specs/` 尚无归档的主规格；与进行中的 `add-yiyu-desktop-translator` 变更之间的视觉和布局冲突，在本变更实施前按设计文档协调，不能把未归档的 delta 当作已存在的主规格。

## Impact

- `web/src/views/` 四类窗口、共享 UI 组件、主题 tokens、动效和 mock/截图交互测试。
- 背景图片需要扩展 `web/src/lib/contract.ts`、前后端设置与状态、Tauri 本地选图和受限文件读取/存储；修改不得破坏现有版本迁移和 settings revision 语义。
- 需要检查现有 Tauri 窗口、CSP/capabilities 和 macOS/Windows 合成边界，以真实设备验证非激活浮窗、背景、模糊及资源占用。
- 用户确认的概念与完整界面规划位于 `docs/design/yiyu-frontend-redesign.md`；该规划和效果图是设计参考，非已实现的前端。
